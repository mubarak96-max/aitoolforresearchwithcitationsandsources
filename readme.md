# Methods & Sources

**Practical guides to research methods, academic writing and AI research tools, for students, researchers and professionals.**

Methods & Sources is a free library of 51 in-depth guides covering every stage of research, from finding a gap in the literature to publishing a paper. Each guide explains the method first, with steps, worked examples and templates, then shows where AI can help and how to check what it gives you.

The site is published by the team behind [AI for Research](https://aiforresearch.app/), an AI research assistant that answers from 250M+ real papers and cites every claim.

## Editorial principles

- **Method before product.** Every guide has to be useful to a reader who never signs up for anything.
- **Primary sources.** Rules and standards link to the people who set them: PRISMA, the EQUATOR Network, COPE, ICMJE, the Cochrane Handbook and the official style guides.
- **Fair comparisons.** When another tool is better for a job, the guide says so.
- **Disclosure.** Methods & Sources is published by the AI for Research team. The full policy is in `about.html`.

## Project structure

Plain HTML and CSS. No framework, no build step needed to serve the site.

```
index.html            Home page
about.html            About and editorial policy (with disclosure)
404.html              Not-found page
robots.txt
guides/
  index.html          Guides hub (generated by scripts/build.mjs)
  *.html              51 guides
assets/
  css/style.css       The only stylesheet
  favicon.svg
scripts/
  build.mjs           Rebuilds the hub; writes sitemap.xml when given a domain
```

The site holds no domain: canonical tags and structured data use root-relative URLs, so it works on any host.

## Working on the site

**Preview locally.** Open `index.html` in a browser. Links between pages are relative, so this works without a server. The 404 page uses root paths, so check it on a local server instead, such as `npx serve .`.

**Add a guide.**

1. Copy an existing file in `guides/` and rename it to the new slug, such as `guides/how-to-write-a-literature-review.html`.
2. Update the title, meta description, canonical, JSON-LD (Article, BreadcrumbList, FAQPage), `<h1>`, body, table of contents and FAQ.
3. Add the slug to a category in `CATEGORIES` at the top of `scripts/build.mjs`.
4. Run `node scripts/build.mjs` to rebuild `guides/index.html`.

**Before deploying,** generate the sitemap with your domain:

```
node scripts/build.mjs https://your-domain.com
```

This writes `sitemap.xml` and adds a `Sitemap:` line to `robots.txt`. Needs Node 18 or later.

## Deploying

Any static host works, including Cloudflare Pages, Netlify, GitHub Pages and S3. Upload everything except `scripts/` and `readme.md`, set `404.html` as the error page, then submit `sitemap.xml` in Google Search Console.
